# ナレスク ローカル検証

授業スケジュール、生徒管理、スタッフシフト、自動割当を架空データで試すための Svelte 5 アプリです。

## 起動

Node.js 22.13 以上と npm を使用します。

```sh
npm ci
npm run dev
```

ブラウザで `http://127.0.0.1:5173` を開きます。ログインや環境変数の設定は不要です。
管理者相当の画面を検証できます。実際の認証・権限判定を検証するものではありません。

保存操作はローカルサーバーのメモリに反映されます。サーバーを終了・再起動すると、変更は破棄されて架空データに戻ります。同じサーバーを開くタブ間ではデータを共有します。
個人情報や実際の認証情報を入力しないでください。

## 試せること

- 日別・月別の授業表示、生徒情報、希望スケジュールの編集
- スタッフの担当科目・シフト希望・配置の確認
- 翌月の授業作成、自動割当、振替、授業メモ
- 保存時の更新競合と変更履歴

「検証用教室（希望・在籍・科目）」と「検証用別教室」を用意しています。
翌月・翌々月は「月の予定作成」から授業を生成して割当を試せます。

## 対象外

外部ログイン、メッセージ送受信、勤怠連携、データ取込、共有リンク発行、ブラウザ拡張は実行できません。
外部 API やデータベースへの接続処理は含めていません。未対応の操作には検証対象外と表示します。

開発サーバーはループバック接続に限定しています。ビルド・プレビュー・デプロイ用のコマンドは提供しません。
ブラウザからの外部通信も制限しています。この制限は、このリポジトリを変更せずに使用する場合の動作です。

## 検証

```sh
npm run check:ui
npm test
```

`ui/` は画面、`lib/` はスケジュール計算、`local/` はメモリ上の検証用 API、`scripts/local-sample.mjs` は架空データの生成処理です。
