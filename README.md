# ナレスク — 授業・シフト管理

教室運営のための授業スケジュール・生徒・スタッフシフト管理アプリです。
生徒の受講希望と講師の担当科目・出勤条件をもとに、授業の作成から担当の割り当て、日々の変更までを扱います。

Svelte 5 と TypeScript、UI コンポーネントライブラリ `@mutsuna/ui` で構築しています。
画面の改善、割当ロジックの改良、不具合修正などのコントリビューションを歓迎します。

## 主な機能

- **授業スケジュール**：日別・月別の表示、授業の作成、振替、欠席、授業メモ
- **生徒管理**：所属教室・受講科目・在籍期間・希望スケジュールの管理
- **スタッフ・シフト管理**：担当教室・科目、出勤希望、授業への配置
- **自動割当**：希望や勤務条件を考慮した割当案の作成と、変更内容を確認してからの反映
- **変更の管理**：保存前の変更確認、更新競合の解決、変更履歴

## 開発を始める

Node.js 22.13 以上と npm を使用します。リポジトリをクローンして、次のコマンドを実行してください。

```sh
npm ci
npm run dev
```

ブラウザで `http://127.0.0.1:5173` を開きます。環境変数や外部アカウントの設定は不要です。
サンプルデータを使って、管理画面とスケジュール計算の開発を始められます。

### 開発環境の仕様

このリポジトリはローカル開発に対応しています。サンプルデータはすべて架空のもので、保存した変更はローカルサーバーのメモリに保持されます。同じサーバーを開くタブ間で共有され、サーバーを再起動すると初期状態に戻ります。

外部ログイン、メッセージ送受信、勤怠連携、データ取込、共有リンク発行、ブラウザ拡張は対象外です。実際の認証・権限判定や外部 API・データベース接続は含まれていません。

サーバーはループバック接続に限定し、ブラウザからの外部通信も制限しています。ビルド・プレビュー・デプロイ用のコマンドは提供していません。

### サンプルデータ

2つの教室に、担当科目や受講希望の異なる生徒・スタッフを用意しています。翌月・翌々月を選び、「月の予定作成」から授業を生成すると、自動割当や配置の調整を確認できます。

## コントリビュート

不具合報告や改善提案は Issue、コードやドキュメントの変更は Pull Request で受け付けています。大きな仕様変更は、実装前に Issue で相談してください。

1. このリポジトリを Fork し、変更用のブランチを作成します。
2. 変更を実装し、ローカルで動作を確認します。不具合修正や計算ロジックの変更には、再現条件を確認できるテストを追加してください。
3. 次のチェックを実行します。

   ```sh
   npm run check:ui
   npm test
   ```

4. このリポジトリの `main` に向けて PR を作成します。変更の目的・内容・確認結果を記載し、画面の変更にはサンプルデータで撮ったスクリーンショットを添えてください。

画面や計算ロジックの変更と、ローカル API の変更は区別して説明してください。変更を目的ごとに小さくまとめるとレビューしやすくなります。
コード・Issue・PR・画像には個人情報や認証情報を含めず、再現にはサンプルデータを使用してください。

## コード構成

| ディレクトリ | 内容 |
| --- | --- |
| `ui/` | Svelte の画面・コンポーネント |
| `lib/` | スケジュール計算、割当、データ編集・マージ |
| `local/` | ローカル開発用のメモリ API |
| `scripts/local-sample.mjs` | サンプルデータの生成 |
| `tests/` | 割当・保存・ローカル API のテスト |
